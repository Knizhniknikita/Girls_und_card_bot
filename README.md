# Telegram Bot "Girls und Card"

Коллекционная карточная игра (CCG) в Telegram с внутриигровой экономикой. 
Аудитория: 700+ активных пользователей (международная).

## 🚀 Возможности
- **Гача-система:** Выдача карточек с системой редкости (от 2 до 4 звезд).
- **Инвентарь:** Отображение карточек с группировкой дубликатов (до 5 штук в стопке).
- **Экономика:** Внутренние баллы, переводы между пользователями (`/give`), магазин карточек (`/buy`).
- **Крафт:** Переработка 3-х дубликатов в карточку более высокого уровня (`/craft`).
- **Торговля:** Передача карточек другим игрокам (`/givecard`).
- **Мини-игра:** Слот-машина "Казино" с асинхронной анимацией и контролем баланса (`/casino`).

## 🛠 Стек технологий
- **Язык:** Python 3 (Aiogram 3)
- **База данных:** SQLite (sqlite3)
- **Архитектура:** Асинхронные хендлеры, работа с транзакциями БД, обработка ошибок ввода.

## ⚙️ Как запустить локально
1. Установите зависимости: `pip install -r requirements.txt`
2. Создайте файл `.env` по примеру `.env.example` и укажите токен бота.
3. Поместите папку `Characters` с изображениями в корень проекта.
4. Создайте базу данных `my_database.db` (таблица `User`).
5. Запустите бота: `python Main.py`

Проект написан в учебных целях для демонстрации навыков работы с Telegram Bot API, SQL и асинхронным Python.
